The homepage follows the wireframe's section order, six navigation destinations, card counts, headings, and overlapping about photos. Spacing, typography, footer details, and the native occasion dropdown remain adaptations. The reviewed prototype/component files cover the occasion control, rather than a complete booking/customer/confirmation screen set.

The React source is in [src](../src). Design references describe the intended UI; they are not executable React code.
