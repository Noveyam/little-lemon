# Figma design references

Design files used when reviewing this Little Lemon React project.

| Figma file | Reference |
| --- | --- |
| [Capstone Wireframe](https://www.figma.com/design/sDGO6I3nW2DXVtR0EJ2Jdc/Capstone-Wireframe) | Desktop homepage layout and section order. |
| [Capstone prototype](https://www.figma.com/design/8vgax1j2qlK1CjAndCHbw1/Capstone-prototype) | Occasion-control prototype example. |
| [Capstone Components](https://www.figma.com/design/4iaV01GZnW7yTLh2WeBloE/Capstone-Components) | Occasion dropdown examples and selected states. |

Open a link above in Figma, or double-click the matching `.webloc` shortcut on macOS. These shortcuts point to the original design files; they are not exported `.fig` documents. Figma retains its existing access permissions and may require sign-in.

The homepage follows the wireframe's section order, six navigation destinations, card counts, headings, and overlapping about photos. Spacing, typography, footer details, and the native occasion dropdown remain adaptations. The reviewed prototype/component files cover the occasion control, rather than a complete booking/customer/confirmation screen set.

The React source is in [src](../src). Design references describe the intended UI; they are not executable React code.
